
| Archivo | Descripción |
|---|---|
| **CapturaCamara.py** | Captura video desde la webcam y muestra 4 ventanas en tiempo real: el video original y tres canales de color separados (R, G, B) usando OpenCV. Se cierra con la tecla Escape. |
| **Casa.py** | Dibuja una casa 3D con OpenGL (paredes, techo, puertas, ventanas) usando primitivas geométricas manuales como cubos y pirámides. |
| **CasaTexturas.py** | Similar a `Casa.py` pero aplica **texturas** a las superficies de la casa cargando imágenes desde archivos. |
| **Clasificacion con haarcascades.py** | Detecta rostros en imágenes o video usando **clasificadores de Haar Cascades** de OpenCV (`cv2.CascadeClassifier`). |
| **Colores.py** | Muestra conversiones entre espacios de color (RGB, HSV, etc.) y aplica filtros de color básicos usando OpenCV. |
| **Cubo 1.py** / **Cubo1.py** | Dibuja un cubo 3D rotando en tiempo real con OpenGL y GLFW. Versiones idénticas del mismo ejercicio. |
| **Degardado.py** | Genera un degradado de colores en una imagen usando NumPy y lo muestra con OpenCV. |
| **Deteccion de manos.py** | Detecta y rastrea las manos en tiempo real desde la webcam usando **MediaPipe Hands**, dibujando los landmarks sobre el video. |
| **Escalamiento.py** | Aplica transformaciones de **escalamiento** (zoom) a una imagen usando OpenCV. |
| **Escalamiento con traslacion.py** | Combina **escalamiento y traslación** en la misma transformación afín sobre una imagen. |
| **FiguraIsometrica.py** | Dibuja una figura geométrica con proyección **isométrica** usando líneas y polígonos en OpenCV o OpenGL. |
| **FiguraPuntillismo.py** | Crea un efecto de **puntillismo** sobre una imagen, reemplazando regiones por puntos de color usando OpenCV. |
| **Invertir colores.py** | Invierte los colores de una imagen (efecto negativo) usando la operación `cv2.bitwise_not`. |
| **MediaPipeOpenGLFW.py** | Combina **MediaPipe + OpenGL + GLFW**: detecta landmarks de manos con la webcam y los usa para controlar o animar objetos 3D en pantalla. |
| **Objetos.py** | Muestra una **galería de 12 figuras 3D de OpenGL** (esfera, cubo, cono, toroide, tetera, cilindro, dodecaedro, etc.) en una cuadrícula 4×3, todas rotando. |
| **Snowman.py** | Anima un **muñeco de nieve** en 3D usando OpenGL+GLFW: la cabeza sube y baja en bucle simulando un salto. |
| **prueba.py** | Script rápido de prueba que carga una imagen (`Dorohedoro.jpg`) y la muestra junto con una imagen gris generada con NumPy. |
